# Pos_System_CS

This repository contains the POS System (C# WinForms) project targeting .NET Framework 4.8.1.

What's included
- Full Visual Studio solution and project files
- Form-based UI in Pos_System_CS project

To get started
1. Open Pos_System_CS.slnx in Visual Studio 2022/2026.
2. Build the solution.
